# Student Blog

A beginner-friendly blogging website built using **HTML, CSS and JavaScript**.

## Features

- Responsive landing page
- Explore latest posts
- Demo login
- Create a blog post
- Choose a category
- Edit your own posts
- Delete your own posts
- Posts are saved with browser `localStorage`
- No backend required
- Ready to upload to GitHub Pages

## Files

- `index.html` — website structure
- `style.css` — design and responsive styling
- `script.js` — login, create/edit/delete posts and local storage

## How to run

Open `index.html` in a browser.

## How to upload to GitHub

1. Create a GitHub account if you do not already have one.
2. Create a new repository, for example `student-blog`.
3. Upload `index.html`, `style.css`, `script.js` and `README.md`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will give you a public website link.

## Important note

This version is a frontend project. The login is only a demo and posts are stored in the browser using localStorage. A real multi-user blog would need a backend/database such as Firebase, Supabase, Node.js + Express, etc.
